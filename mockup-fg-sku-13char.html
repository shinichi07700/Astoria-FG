3 · SKU Recode (one-time, Admin)

Legacy rows keep their FFS|FPS id and downstream documents untouched. The tool proposes a 13-char code oldest-first; Seq & Size can be overridden before confirming. The old code is kept as Legacy Code. Export crosswalk maps old → new for Finance / Accurate.

4 · Revision dialogs

Two separate actions replace the old single “Revision” button. Formula revision keeps the same code; packaging revision issues a new code at the higher FPS revision and discontinues the old one. Both clear NA → Pending BPOM.

Formula revision — BRLEYCP012A01

Keeps the same SKU code; swaps the formula link; clears NA (BPOM recertification). The new formula must have the same category + dosage form.
